Free Color is a Python-based drawing program created in Visual Studio Code, where the player draws on a canvas and can adjust the drawing style and color to their liking.

Features

Click, hold, drag drawing design
Shape paintbrush options
Size paintbrush options
Clear canvas
Color canvas option

IMPORTANT: This project has been primarily tested on Windows. It may also work on macOS and Linux, but compatibility has not been fully verified.

This is the first release of Free Color. Feedback, bug reports, and suggestions are welcome via the Issues tab.
